# Cut

Windows 截图工具，使用 C# / WPF 和 Win32。默认快捷键 **Ctrl + Alt + A**；截图、长截图、标注、二维码和文字识别全程在本地处理，可另行配置 Azure 在线中英翻译、AI 文字助手和 AI 看图。当前版本 **0.11.0**。

## 运行

发布包支持 Windows 10/11 x64，包含 .NET 运行时、CPU OCR 引擎和模型。解压整个文件夹后运行 `Cut.exe`；本地截图、二维码和 OCR 无需安装 Python、配置接口密钥或下载模型。升级前从托盘退出旧版，不要只复制 EXE。

源码开发需要 .NET 8 或更高版本 SDK；普通开发构建需要 .NET 8 Desktop Runtime。首次构建先下载并校验模型：

```powershell
& .\Tools\download-ocr-models.ps1
dotnet run --project .\Cut.csproj
```

首次运行显示设置窗口。关闭设置窗口后程序继续在系统托盘运行；双击托盘图标打开设置，通过托盘菜单退出。快捷键被占用时可在设置中修改，或点击“开始截图”。配置保存在 `%LOCALAPPDATA%\Cut\settings.json`。

## 操作

| 操作 | 行为 |
| --- | --- |
| Ctrl + Alt + A | 冻结桌面，进入框选 |
| 移动鼠标 / 单击 | 自动预选鼠标下的窗口 / 锁定为选区 |
| 左键拖拽 | 创建选区 |
| 拖动选区内部 / 边框 | 移动 / 调整选区 |
| Enter / Ctrl + C | 复制图片并退出截图（文字输入期间除外） |
| 双击选区 | 尚未进入标注模式时复制；标注模式不触发复制 |
| Ctrl + S / 保存按钮 | 保存 PNG，成功后退出截图 |
| Ctrl + Q / 识别二维码按钮 | 识别选区中的单个或多个二维码 |
| Ctrl + T / 识别文字按钮 | 离线识别中英文混排文字，编辑并复制 |
| Ctrl + I / AI 看图按钮 | 直接预览选区图片，选择任务后发送至视觉模型分析 |
| Ctrl + L / 长截图按钮 | 实时显示原窗口，手动或自动滚动并拼接长图 |
| Ctrl + Z / Ctrl + Y | 撤销 / 重做标注；文字框内使用文本编辑自身的撤销重做 |
| Delete | 删除当前选中的标注；文字输入期间删除文字 |
| 右键 | 标注模式取消当前操作并切换选择工具；其他情况下清除选区，无选区则退出 |
| Esc | 先取消未完成的笔画或文字编辑，再按一次退出截图 |

进入截图模式后，鼠标经过窗口会显示与窗口可见边框一致的预选框；单击选定后可以移动、缩放、复制、保存或识别内容。按住拖动始终可以自由框选。右键清除已选区域后恢复自动预选；预选期间右键退出。Enter / Ctrl + C、Ctrl + S、Ctrl + Q、Ctrl + T 也可以直接对当前预选区域操作。

窗口位置和层叠次序在抓取屏幕前记录，预选框与冻结画面对应；忽略 Cut 自身、隐藏、最小化及其他虚拟桌面上的窗口。优先使用 DWM 可见边框，排除不可见的调整大小边缘。鼠标下没有应用窗口时预选所在显示器。首版识别顶层窗口，不识别网页内部元素；被其他窗口遮住的内容不会被补全，导出的仍是屏幕上实际可见的画面。

0.3.1 修复显卡/录屏软件的透明覆盖层被误当成全屏窗口的问题：忽略鼠标穿透的分层窗口以及全局透明度为零的窗口，正常可交互的半透明窗口仍可预选。

支持多显示器、负坐标和跨屏框选；不同缩放比例的显示器按物理像素裁剪，不重采样。显示器之间没有实际屏幕的区域输出为黑色。显示器布局变化时取消当前截图。

## 截图标注

框选后使用工具栏中的矩形、椭圆、箭头、画笔、文字、马赛克和实色遮挡。工具栏顶部可拖动，避免挡住要标注的位置；窄屏会自动换行。

- 提供六种颜色、三档线宽和四档字号。矩形和椭圆为空心；实色遮挡为不透明填充，默认黑色。马赛克按 16 × 16 物理像素分块，粗细控制涂抹范围。
- “选择”工具点击标注后可拖动；矩形、椭圆、遮挡块可拖动四角调整大小，箭头可拖动两端。画笔和文字可整体移动；颜色、线宽和字号可修改当前选中的对象。马赛克只支持撤销重做，不支持单独选择移动。
- “文字”工具点击输入，Enter 换行，Ctrl + Enter 完成，Esc 放弃本次编辑；用“选择”工具双击已有文字可修改。文字最多 4000 字符，自动换行；绘制超出选区的部分会被裁掉。点击复制、保存、识别或 AI 看图时会先提交正在输入的文字。
- 第一笔标注完成后锁定截图区域，避免移动选区导致标注错位。撤销全部后仍保留锁定，方便重做；要更换选区请点击“重新框选”，确认后清除标注和历史。
- 支持最近 100 次操作的撤销/重做；包括新增、移动、调整大小、样式、文字修改和删除。撤销后执行新操作会清空重做记录。单笔画笔/马赛克最多记录 20000 个轨迹点，达到后请松开鼠标另起一笔。
- **复制、保存、二维码识别、OCR、AI 看图，以及 OCR 窗口中的原图预览，都使用同一份标注后的合成图片。** 工具栏、选中边框和编辑控件不会进入导出图片。返回选区继续编辑会保留全部标注。
- 马赛克基于此前已合成的画面处理，后画马赛克不会重新取出实色遮挡下的原图。需隐藏内容时优先使用实色遮挡；导出 PNG 为合成位图，不附带原图或可编辑标注层。会话内仍可通过撤销恢复，退出后不保存编辑工程。
- 标注上限为 3200 万像素，采用选区局部物理像素坐标，支持负坐标和跨屏。OCR 自身仍保留 1600 万像素限制；AI 图片尺寸限制不变。

## 滚动长截图

1. 框选网页正文或聊天消息区域，点击“长截图”或 **Ctrl + L**。选区必须在同一显示器内，至少 128 × 160 像素；已有标注时会提示重新采集，原标注不会带入长图。
2. 选择“向下 · 网页”或“向上 · 聊天历史”。方向在首帧记录后固定。排除顶部/底部设置以物理像素计，用于去掉悬浮导航栏和输入框；裁去后至少保留 120 像素高度。
3. 点击“开始”，等首帧记录后，把鼠标移入内容区手动滚动。建议每次滚动约 1/3 屏，稍停约半秒让画面稳定；程序自动找重叠区域并追加新内容。向上采集会在图片顶部追加，保持聊天阅读顺序。
4. 工具栏显示预计长图尺寸、已缓存原图数量和最近一张原图的小预览。“暂停 / 继续”保留缓存；“撤销拼接”移除最近一段并暂停，请把页面滚回上一处再继续。“完成”在后台统一生成长图，再进入长图编辑；“取消”结束本次截图。工具栏有焦点时 Esc 先暂停，再按一次取消。
5. 在编辑窗口用滚轮浏览、适应宽度或缩放查看接缝，使用矩形、椭圆、箭头、画笔、文字、马赛克、实色遮挡及撤销重做。选择“框选局部”可裁剪输出范围；“全图”恢复完整输出，原图和标注不被永久裁掉。
6. 复制、保存 PNG、OCR 和 AI 看图都使用标注后的当前输出范围。长图较长时请先框选局部识别/分析；OCR 上限仍为 1600 万像素，AI 长边超过 4096 时会缩小并提示。保存取消、复制失败、识别失败均保留长图供重试。

程序只采集选定区域，使用当前屏幕上实际可见的内容，不获取窗口被遮挡部分，不上传原图。工具栏尽量放在选区外；Windows 10 2004 及之后使用系统截图排除功能。旧系统或排除失败时，若工具栏覆盖选区，会暂停并提示移开工具栏。绿色边框位于采集区域外。

**自动滚动（0.10.0）：** 选择“自动滚动”，选择向上/向下及慢速、标准或快速，点击“开始”，在倒计时内将鼠标移入内容区。程序先记录稳定首帧，再逐次发送滚轮输入；每次等待画面稳定、拼接验证完成后才继续。速度影响输入量和等待时间，实际速度受目标程序响应影响；不会跳过拼接校验。

**0.11.0 自适应采集与原图缓存：** 从小幅滚动开始，按上一轮实际位移校准滚轮量。慢速、标准、快速的目标分别为有效选区高度的 45%、60%、65%；每次输入量最多增加约 50%，位移过大时回调，保留重叠。系统滚轮不等于像素，目标比例是自适应目标，不是精确定位保证。

- 稳定性检测周期改为 100 ms，仍需连续两次稳定比较；三档最小等待分别为 650 / 350 / 200 ms。实际遇到加载或动画时继续等待，不按固定倒计时盲目截图。
- 匹配和磁盘写入在后台运行，每次最多处理一对原图；确认重叠且缓存成功才继续发送滚轮，处理慢时自然减速。固定背景页面记住匹配策略，后续优先使用较少特征点快速匹配，置信度不足则回退完整检查。
- 完整原始截图（包括重叠区域）写入系统临时目录中本次会话独占的 `Cut-scroll-*.cache` 文件，内存仅保留最近原图及小预览，不实时重建完整长图。缓存使用无损原始像素，单会话上限 1 GiB；达到上限或写入失败后暂停，允许完成已有内容。
- “完成”从原图缓存统一读取已确认的片段，在后台合成长图。失败时保留缓存供重试；取消、成功进入编辑器或退出进程时，系统关闭文件句柄并删除临时缓存。暂停保留缓存；不支持程序退出后恢复会话。
- 撤销会从缓存恢复上一张完整原图，避免固定背景页面由拼接片段重建匹配基准。等待匹配期间仍可暂停；迟到结果不会追加内容或触发滚轮。

- 自动模式下，全局 **Esc**、手动滚轮、点击或键盘操作会暂停；鼠标离开选区、目标失去焦点、被遮挡或移动/缩放也会暂停。监视输入仅用于当前会话的暂停，不保存按键或鼠标记录，暂停和关闭时释放监听及 Esc 快捷键。
- 暂停后可切换三档速度，或改为手动滚动，再点击“继续”。方向在首帧记录后固定。继续前先对齐当前画面与已有结果，能可靠拼接才会再滚动；撤销后应手动滚回上一处。
- 连续多次滚动尝试且至少 5 秒没有新内容时自动停止。目标控件通过系统辅助功能报告顶部/底部时显示“已到顶部/底部”；无法读取滚动位置时显示“未检测到新内容，已停止”。后者也可能是加载延迟、滚轮未响应或空白区域，并不保证已到真正的边界。
- 停止后保留缩略图、像素尺寸和已拼接内容，不自动跳到编辑窗口。加载更多消息/网页内容后可点击“继续”；点击“完成”才进入标注。持续动画或无法可靠匹配时暂停，防止继续滚动越过内容。
- 输入发送失败会单独提示，不作为到达边界处理。权限较高的目标窗口可能无法接收自动输入，此时可使用手动模式。选区只应覆盖一个可滚动内容区，排除固定标题栏和输入框；不支持在一次采集中自动切换多个滚动面板。

**0.10.1 网页拼接修复：** 对 paldb.cn/pals 一类“固定壁纸 + 半透明卡片”的页面，原先整个重叠区必须近似一致的判断会误报拼接失败。现在优先使用原像素匹配，失败时尝试跟踪分布在多个区域的独特文字、图标和图案，验证一致的纵向位移；仍拒绝歧义、反向运动、局部动画和大范围未解释的画面变化。全部计算在本地完成。

- 首次匹配失败时额外等待最多约 1.5 秒，让图片加载和悬停效果结束；等待期间不发送下一次自动滚轮输入，超时后暂停并保留预览。错误信息区分固定栏、内容变化和重叠不足。
- 固定背景和滚动正文无法同时对齐，输出以正文为准，壁纸可能出现接缝，识别到这种页面时显示提示。顶部悬浮导航、底部输入框仍应通过选区或“排除顶部 / 底部”去掉，不会自动删除。
- 画面稳定后才尝试拼接，使用多个位置的图像匹配并校验重叠区域。不可靠的匹配会暂停，保留已完成内容；可滚回上一处后继续，或完成已有结果再分段截取。
- 滚动过快、反向滚动、大量重复内容、悬浮栏、动画、大范围动态加载或布局变化可能无法匹配。没有变化时不重复追加，也不会把“暂时没动”直接当作到达底部；可等待加载再继续。
- 目标窗口移动、改变尺寸、最小化、失去前台或检测到遮挡时暂停；显示器布局变化沿用普通截图的取消机制。采集时请勿切换其他窗口或改变网页缩放。
- 输出上限为高度 30,000 像素、总像素 3,200 万、最多 1,000 次拼接；另有 1 GiB 原图缓存上限，先达到哪个就停止追加。完成后统一合成长图，不保存每一步完整长图的历史副本。
- 支持固定宽度的纵向手动/自动滚动，不支持横向拼接或跨显示器采集。长图编辑窗口暂不提供二维码识别入口，普通截图入口保持不变。

## 二维码识别

框选完整二维码（包括周围空白）后，点击“识别二维码”或按 **Ctrl + Q**。

- 多个结果以列表展示，相同内容合并；选中一项查看完整文本。
- “复制内容”复制选中项的原始文本，成功后退出截图。
- HTTP/HTTPS 网页显示“打开链接”，点击后通过系统默认浏览器打开，并退出截图。其他内容只作为文本显示。
- 关闭结果窗口、按 Esc 或点击“返回选区”回到原选区。
- 未找到二维码或识别出错时保留选区；可以调整范围重试。
- 识别在后台进行，识别期间 Esc 可立即退出截图；迟到的结果不会弹窗。
- 原图和反色图均会扫描，支持同一选区中混合黑白极性的二维码。较小图片未识别到时尝试有限放大。超过 3200 万像素的选区会提示缩小。
- 不上传图片，不自动打开链接，不自动覆盖剪贴板。无法保证识别缺角、模糊或像素不足的二维码。

## 文字识别（OCR）

框选文字后点击“识别文字”或按 **Ctrl + T**。支持中文、英文、数字、常用标点及混排；使用 PP-OCRv5 mobile 检测/识别模型与 ONNX Runtime CPU，无网络请求。

- 结果窗口可展开查看原图；原文和译文并排显示，均可编辑。OCR 默认保留识别行的换行。
- 选中文字后点击“复制选中”或按 Ctrl + C，复制编辑后的选中部分，窗口保持打开。
- “复制原文并完成”或原文框内 Ctrl + Enter 复制当前编辑内容，成功后结束截图；失败时保留修改供重试。
- “合并换行”作用于当前编辑内容，可 Ctrl + Z 撤销；不会自动合并换行或自动覆盖剪贴板。
- 结果窗口的 Esc / 返回选区保留原选区；识别期间 Esc 立即退出截图，迟到的结果不会再次弹窗。
- 模型首次使用时加载，后续复用。后台工作串行运行，支持取消推理。使用原始截图像素；大图按重叠区域分块，合并重复区域和横向跨块的文本行。
- 最多 1600 万像素、500 个文本区域；极长单行（缩放到 48 像素高后超过 4096 像素宽）会提示分段框选，避免静默截断。缺模型或文件损坏时提示重新解压完整发布包。
- 初版重点是横向印刷体截图。空格、复杂多列版面、低清晰度、手写、竖排、旋转文字可能需要手工修正；不承诺表格结构、公式或原版式还原。结果可编辑，请核对重要内容。

模型下载地址、固定版本与 SHA256 见 `Models/manifest.json`；大模型文件不提交 Git，由 `Tools/download-ocr-models.ps1` 重建，发布包内附带。输入图像仅在内存处理，不保存到磁盘或上传。测试仅生成合成样本和预览。

## 在线翻译设置与使用

本版接入 **Microsoft Azure Translator Text API v3**，支持自动检测源语言，以及简体中文和英文互译。未配置时，OCR、编辑和原文复制仍可使用；程序不会附带共享密钥或自动申请付费资源。

1. 在 Azure 门户创建 Translator 资源，在“密钥和终结点”中取得密钥及区域。官方说明：[认证配置](https://learn.microsoft.com/azure/ai-services/translator/text-translation/reference/authentication)。
2. 从主窗口点击“翻译服务设置”，或在 OCR 结果窗口点击“翻译设置”。通常保留默认地址 `https://api.cognitive.microsofttranslator.com`。区域型 / 多服务资源填写对应区域代码（例如 `eastasia`）；全局单服务资源可留空。
3. 填写自己的密钥，点击“测试连接”。测试仅发送固定示例 `Hello`，成功后再点击“保存”；测试不会自动保存配置。清空密钥后保存可停用翻译。
4. OCR 后选择目标语言，点击“翻译全部”，或先在原文中选中文字，再点击“翻译选中”。翻译使用当前编辑后的内容。
5. 译文可继续校对，使用“复制选中译文”或“复制译文并完成”。Ctrl + C 复制当前编辑框选中文字；Ctrl + Enter 复制当前编辑框全部内容并完成截图。

也支持 `api-apc` / `api-eur` / `api-nam.cognitive.microsofttranslator.com` 区域端点，以及 `https://资源名.cognitiveservices.azure.com` 自定义资源域名；自定义域名自动使用 `/translator/text/v3.0/translate` 路径。当前仅支持这些 Azure 官方 HTTPS 地址，不支持任意代理、其他厂商或中国区独立端点。

- 仅在明确点击翻译时上传当前待翻译的文字，不上传截图。在线翻译依赖网络和有效服务资源，费用/额度由自己的 Azure 套餐决定；打开 OCR 窗口不会发送请求。
- 单次上限 5000 个 UTF-16 字符，超长内容请选中部分分段翻译。默认 30 秒超时。错误提示区分密钥/区域错误、权限问题、限流/配额、网络与服务故障，不自动重试可能计费的请求。
- 原文或语言发生变化时标记“译文待更新”；正在请求时会取消，保留已有译文。手动编辑译文、关闭窗口或取消后，迟到的响应也不会覆盖当前内容。
- 翻译期间 Esc 先取消翻译；再次 Esc 返回截图选区。失败或取消后可重试，原文和已有译文不清空。
- 密钥通过 Windows DPAPI CurrentUser 加密保存到 `%LOCALAPPDATA%\Cut\translation.json`，与截图快捷键配置独立。不要复制该文件到其他用户或电脑；迁移后需重新填写密钥。程序不记录翻译原文、译文或密钥到日志。
- “翻译服务设置”打开时暂停快捷键启动截图，避免把正在配置的窗口截入画面。

本次交付为可配置版本：用户尚无 Azure Translator 资源，**没有进行真实密钥的在线翻译实测**。本地测试使用模拟 HTTP 响应验证请求、解析、错误处理和完整界面流程，不代表服务端翻译质量或账户连通性验证。取得资源后请先用设置页的“测试连接”验证自己的配置。

## AI 助手

截图后按 **Ctrl + T** 提取文字，再切换右侧的 **AI 助手** 页签。此入口基于 OCR 文字理解，支持读懂截图文字、解释报错、总结重点、润色和自定义提问。要直接分析图片，请使用下面的“AI 看图”入口。

1. 从主窗口点击“AI 模型设置”，或在 AI 页签点击“模型设置”。
2. 填写兼容 Chat Completions 的**完整接口地址**（包括服务商要求的路径前缀和 `/chat/completions`）、模型 ID 和自己的 API Key。程序不附带模型账户或密钥，不自动选择模型。仅支持 Bearer Key 鉴权；不支持 Azure OpenAI 的 api-key/query-version 接口或仅支持 Responses 的接口。
3. 远程服务使用 HTTPS；明确配置为本机回环地址时允许 HTTP 和空密钥，例如 `http://localhost:1234/v1/chat/completions`。本地模型服务需自行安装运行。
4. “测试连接”使用当前填写但尚未保存的配置，只发送固定 Hello 示例与“请只回复 OK”任务；不发送截图或 OCR 原文。成功后点击“保存”。
5. 选择任务及“全部原文 / 选中文字”，按需校对左侧原文。自定义模式填写问题后点击“生成回答”。选中范围为空时不会自动改为发送全文。
6. 回答逐步显示，可停止、重新生成。生成结束或停止后可以编辑；Ctrl + C /“复制选中”保留窗口，“复制回答并完成”或回答框内 Ctrl + Enter 完成截图。在自定义问题框内 Ctrl + Enter 生成回答。

- 仅点击生成时发送当前范围内的文字、任务和自定义问题；不上传截图，不自动提交，不附带历史回答。截图文字和模型回答只在内存中处理，程序不把它们或密钥写入日志。
- 原文、选中范围、任务或问题变化时，取消旧请求并提示回答待更新；旧片段不会覆盖新结果。失败或停止时保留已有文字，部分回答提示可能不完整。原文保持独立，可随时校对。
- 单次输入最多 20,000 个 UTF-16 字符，问题最多 2,000 字符；回答接收上限 64,000 字符，总响应与事件也有限制。请求最长 120 秒，无自动重试、重定向跟随或工具执行。实际模型上下文、计费与输出限制以服务商为准。

- AI 输出为可编辑纯文本，不自动打开链接、运行代码或访问文件。内容理解依赖 OCR 准确性，遇到识别错误请先校对原文再生成。
- 模型接口按官方 [Chat Completions 请求格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 和 [流式事件格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events) 实现。服务商需要支持相应的 system/user 消息、文本输出与 SSE 流，亦接受兼容 JSON 回答；不保证所有标为“兼容”的服务或模型均支持。

本次未提供真实模型账户密钥，因此**未实测真实服务连通性、回答质量或计费**。自动测试使用模拟传输与合成文字，覆盖协议、加密存储、取消竞态及完整界面流程；配置实际服务后请先执行“测试连接”。

## AI 看图

在截图模式中点击工具栏的 **✦ AI 看图**，或按 **Ctrl + I**。快捷键也可直接锁定鼠标下的窗口预选框；无需先执行 OCR，没有文字的图片也能提交。OCR 结果窗口另有“用 AI 分析原图”入口。

1. 在主窗口或看图窗口打开“视觉模型设置”。填写支持图片输入的模型 ID，以及兼容 Chat Completions 的完整接口地址和 API Key；也可勾选“沿用文字 AI 的服务地址和密钥”，仅单独填写视觉模型 ID。地址要求与文字 AI 相同。设置页显示继承时实际使用的地址。
2. 点击“测试图片理解”。程序只发送本地生成的随机六位验证码图片与固定问题，不发送当前截图，也不在问题中透露验证码。正确读出验证码才显示通过；收到普通 OK 或错误数字不算通过。该测试仅验证基本图片读取能力，不代表复杂界面、图表的分析质量。测试不会自动保存，完成后点击“保存”。
3. 框选后打开 AI 看图，左侧预览实际准备发送的图片，支持适应窗口、100% 和缩放；顶部显示原选区尺寸、发送尺寸和 PNG 体积。
4. 选择“读懂截图 / 理解界面 / 分析图表 / 解释报错 / 自定义提问”，点击“开始分析”后才发送。右侧流式展示回答，可停止、重新生成、编辑和复制。每次分析为独立请求，不附带历史回答。
5. “复制选中”保留窗口；“复制回答并完成”或回答框内 Ctrl + Enter 结束截图。返回按钮回到原选区（从 OCR 进入时返回 OCR 窗口）；生成期间 Esc 先停止，再按 Esc 返回。任务或问题变更会取消旧请求，迟到片段不会覆盖当前内容。

- 仅发送当前选区图像与任务问题，不发送整张桌面、窗口列表或 OCR 文本。打开窗口和缩放预览均不触发网络请求，准备过程仅在内存完成，无图片临时文件。
- 选区最多 3200 万像素。使用 PNG，普通截图保留原始像素；较大图片等比缩小，发送长边最多 4096 像素、PNG 最多 4 MiB（Base64 请求体会更大）。缩小时会提示，报错小字或密集图表可返回框选局部。服务自身限制可能更严格。
- 使用视觉专用提示处理布局、控件、坐标轴和报错上下文，要求区分可见事实与推断，对看不清的数字或错误码说明不确定。结果只显示为可编辑文本，不执行命令、点击按钮或打开链接。
- 视觉模型配置保存在 `%LOCALAPPDATA%\Cut\vision.json`，密钥用 DPAPI CurrentUser 加密。与文字 AI、Azure 翻译和快捷键配置独立；继承模式在每次请求时读取文字 AI 地址和密钥，保持独立的视觉模型 ID。清空视觉模型名称并保存可停用看图。
- 模型必须同时支持图片输入和所配置的接口；纯文字模型不能用于看图。图片被拒绝时给出提示，不会静默改用 OCR 或文字分析。取消、120 秒超时、响应大小限制和不自动重试机制沿用现有 AI 服务。
- 接口使用文字内容块和 PNG Base64 `image_url` 内容块，参见 [官方图片输入说明](https://developers.openai.com/api/docs/guides/images-vision)。第三方服务需支持相同格式，模型能力与图片计费以服务商为准。

本次交付使用合成图片和模拟服务测试。用户将在软件中自行配置已有服务，**真实视觉模型连通性、界面/图表/报错理解质量及计费尚未实测**。请先运行“测试图片理解”，再用实际截图核对回答。

## 实现

程序、窗口和托盘使用统一的截图取景框图标。SVG 源文件和多尺寸 ICO 位于 `Assets`；托盘采用适合小尺寸的加粗版本。ICO 已嵌入程序，运行时不依赖外部图标文件。重新生成图标的方法见 `Assets/README.md`。

- `CaptureService`：GDI 屏幕快照及按物理像素裁剪、拼接。
- `SelectionController`：独立的框选、移动、调整大小逻辑。
- `AnnotationDocument` / `AnnotationRenderer`：标注对象、命中编辑、撤销重做、物理像素绘制与统一合成；`OverlayWindow.Annotations` 提供工具栏及就地文字编辑。
- `ScrollMatcher` / `ScrollAssembler`：多区域匹配、重叠验证、上下方向分段拼接与撤销；`ScrollCaptureWindow` 管理实时采集、目标窗口和暂停状态；`LongImageEditor` 提供可滚动的长图标注与局部输出。
- `ScrollMatchingSession` / `ScrollCaptureDocument`：会话匹配策略、完整原图磁盘缓存、撤销恢复、限额和统一合成；`ScrollAssembler` 继续用于旧算法对照测试。
- `AutoScrollPacer` / `ScrollCaptureWindow.Auto`：自动滚动节奏、稳定帧闭环、三档速度及边界停止；`ScrollInputService` 发送带标记的滚轮输入并检测用户接管；`ScrollBoundaryService` 限时查询目标控件的辅助功能滚动位置。
- `CaptureSession`：多屏共享状态、复制和保存流程。
- `OverlayWindow`：每个显示器一个 WPF 覆盖窗口，渲染冻结画面、遮罩和工具条。
- `HotkeyService`：Win32 全局快捷键，替换失败时保留原注册。
- `ExportService`：剪贴板 Bitmap + PNG 格式、短暂重试、PNG 文件写入。
- `QrCodeService`：ZXing.Net 本地解码、串行后台工作、取消与有限预处理。
- `QrResultWindow`：结果列表、原始文本、复制与打开链接。
- `OcrService` / `IOcrEngine`：本地模型校验、串行后台推理、检测分块、区域合并、CTC 解码和阅读顺序。
- `OcrResultWindow`：原图预览、文本编辑、部分/全部复制、合并换行和撤销。
- `ITranslationService` / `AzureTranslationService`：可替换的翻译接口、Azure v3 请求与响应、超时取消和安全错误提示。
- `TranslationSettingsStore` / `TranslationSettingsWindow`：DPAPI 密钥加密、独立配置、连接测试和设置界面。
- `IAiService` / `CompatibleAiService`：任务提示、Chat Completions 文本请求、SSE/JSON 解析、取消、超时和响应大小限制。
- `AiAssistantPanel`：任务与范围选择、流式回答、陈旧结果防护、编辑复制。
- `AiSettingsStore` / `AiSettingsWindow`：独立模型配置、DPAPI 密钥加密、固定输入连接测试。
- `VisionImage` / `VisionResultWindow`：选区 PNG 编码和大小限制、图片预览缩放、独立看图窗口；复用 `AiAssistantPanel` 流式回答和编辑复制。
- `LinkService`：仅将 HTTP/HTTPS 网页交给系统默认浏览器。

## 手工验收

- 在微信、画图等程序粘贴截图，检查尺寸和画面。
- 保存对话框取消后仍可调整选区；保存失败后能重试。
- 双屏 100% / 150% 混合缩放、屏幕位于主屏左侧/上方、跨屏拖拽。
- 重复快捷键、连续截图、退出后重新启动，检查残留遮罩和快捷键释放。
- 框选实际网页上的二维码；在记事本粘贴识别文本，点击网页结果验证系统默认浏览器。
